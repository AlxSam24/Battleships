# Battleships – C++ Learning Project

## Overview

This project documents the development of a **Battleships game built in C++**, starting from a very simple console-based implementation and gradually evolving into a more advanced version using modern programming practices and eventually a game engine.

The goal of this repository is not just to produce a final game, but to **demonstrate the progression of software design, programming concepts, and game development techniques** over time.

Each version introduces new ideas, improving the structure, usability, and complexity of the project.

---

# Project Goals

* Learn and practice **C++ programming fundamentals**
* Develop a working implementation of the classic **Battleships game**
* Progressively improve code structure and design
* Introduce **object-oriented programming concepts**
* Transition from a console-based game to a **graphical version using a game engine**

---

# Project Versions

## Version 1 – Basic Console Battleships

**Focus:** Fundamental C++ concepts

Features:

* Simple console interface
* 10×10 grid using arrays
* Basic player input
* Minimal validation
* No object-oriented programming

Concepts practiced:

* Variables and loops
* Arrays and grid structures
* Input/output using `cin` and `cout`
* Basic program flow

Goal of this version:

> Build a working foundation and understand how the core mechanics of the game function.

---

## Version 2 – Improved Game Logic

**Focus:** Cleaner structure and better gameplay logic

Improvements:

* Better input validation
* Ship placement system
* Turn-based gameplay
* Hit and miss tracking
* Improved grid display

Concepts introduced:

* Functions for modular code
* Improved control flow
* Code readability improvements

Goal of this version:

> Move away from a single large `main()` function toward more maintainable code.

---

## Version 3 – Object-Oriented Battleships

**Focus:** Applying OOP principles

Planned improvements:

* Classes for `Board`, `Player`, and `Ship`
* Encapsulation of game logic
* Separation of responsibilities
* Cleaner architecture

Concepts introduced:

* Classes and objects
* Encapsulation
* Code reuse
* Improved scalability

Goal of this version:

> Refactor the project into a structured and maintainable program.

---

## Version 4 – Advanced Gameplay

**Focus:** Expanding features

Possible additions:

* Computer AI opponent
* Random ship placement
* Improved game rules
* Score tracking

Concepts introduced:

* Algorithm design
* Game state management
* More complex program structures

---

## Version 5 – Game Engine Implementation

**Focus:** Transition to graphical game development

The final stage of this project aims to rebuild the game using a **game engine**, such as Unity or another C++ compatible engine.

Planned improvements:

* Graphical user interface
* Interactive game board
* Animations and sound
* Mouse-based input

Concepts introduced:

* Game engine architecture
* Rendering systems
* Event-driven programming
* Game loops

Goal of this version:

> Transform the project from a console application into a **fully playable graphical game**.
